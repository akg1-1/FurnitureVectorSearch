# FurnitureVectorSearch – Поиск векторов мебели по текстовому запросу
Python-класс для векторного поиска мебельных товаров по текстовому запросу с использованием **CLIP** и **Qdrant**.  
Позволяет фильтровать результаты по типу, стилям и цветам.

---
## Возможности
- 🧠 Использование модели **OpenCLIP** (ViT-H-14 по умолчанию) для получения текстовых эмбеддингов
- 🔍 **Гибридный поиск**: релевантность + фильтрация
- 🎨 Фильтрация по:
  - типу (`type`) – точное совпадение
  - стилям (`styles`) – любой из списка
  - цветам (`colors`) – любой из списка
- 🐳 Совместимость с **Qdrant** (облачный или локальный)

---
## 📦 Установка
### 1. Клонирование репозитория
```bash
git clone https://github.com/akg1-1/FurnitureVectorSearch.git
```
### 2. Установка зависимостей
Рекомендуется использовать виртуальное окружение:
```bash
python -m venv venv
source venv/bin/activate   # Linux/macOS
venv\Scripts\activate      # Windows
```
Установите необходимые пакеты:
```bash
pip install -r requirements.txt
```
### 3. Запуск Qdrant
```bash
docker-compose up -d
```
